# TuiCanvas.CellRows

## Syntax

```freebasic
TuiCanvas.CellRows( ) as int32
```

## Description

The canvas height in terminal cells.

## Example

```freebasic
#import "std/tui"
using tui

print TuiCanvas( 40, 10 ).CellRows( )          '' 10
```
