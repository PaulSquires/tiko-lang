# TuiCanvas.CellRows

## Syntax

```freebasic
TuiCanvas.CellRows( ) as long
```

## Description

The canvas height in terminal cells.

## Example

```freebasic
#include once "fb/tui.bi"
using FB

print TuiCanvas( 40, 10 ).CellRows( )          '' 10
```
