# TuiWidget.Kind

## Syntax

```freebasic
TuiWidget.Kind( ) as ustring
```

## Description

A short type name. Used for diagnostics and for asserting what a container ended up holding -- there is no RTTI to ask instead.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiBlock b
dim as TuiParagraph p
print b.Kind( )                   '' Block
print p.Kind( )                   '' Paragraph
```
