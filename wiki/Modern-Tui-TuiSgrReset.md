# TuiSgrReset

## Syntax

```freebasic
TuiSgrReset( ) as string
```

## Description

ESC [ 0 m -- back to the terminal's default everything. The leave sequence starts with this, so no style bleeds onto the main screen.

## Example

```freebasic
#import "std/tui"
using tui

print len( TuiSgrReset( ) )            '' 4
print asc( TuiSgrReset( ), 1 )         '' 27
```
