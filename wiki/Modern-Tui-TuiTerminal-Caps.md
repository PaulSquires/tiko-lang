# TuiTerminal.Caps

## Syntax

```freebasic
TuiTerminal.Caps( ) as TuiCaps
```

## Description

The capabilities detected at Enter. Cached -- detection runs once.

## Example

```freebasic
#include once "fb/tui.bi"
using FB

dim as TuiTerminal term
dim as TuiCaps c = term.Caps( )
print c.isTerminal, c.mouse, c.unicode
```
