# TuiRed

## Syntax

```freebasic
TuiRed( ) as TuiColor
```

## Description

Shorthand for TuiAnsi( TUIC_RED ) -- palette index 1.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiColor c = TuiRed( )
print c.Index( )                  '' 1
dim as TuiStyle s = TuiStyleOf( c, TuiDefaultColor( ), TUIATTR_BOLD )
print s.HasAttr( TUIATTR_BOLD )   '' true
```
