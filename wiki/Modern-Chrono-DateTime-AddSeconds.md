# DateTime.AddSeconds

Returns the date-time moved by a number of seconds, fractions allowed.

## Syntax

```freebasic
DateTime.AddSeconds
```

## Examples

```freebasic
#import "std/chrono"
using chrono

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.AddSeconds( 55 ).Minute      '' 31
print d.AddSeconds( 0.5 ).Millisecond            '' 623
```
