# TuiAmbiguousWide

## Syntax

```freebasic
TuiAmbiguousWide( ) as boolean
```

## Description

The current ambiguous-width setting.

## Example

```freebasic
#import "std/tui"
using tui

print TuiAmbiguousWide( )         '' false -- narrow by default
```
