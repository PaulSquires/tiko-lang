# TuiBuffer.Count

## Syntax

```freebasic
TuiBuffer.Count( ) as int32
```

## Description

cols * rows.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiBuffer b
b.Resize( 200, 50 )
print b.Count( )                  '' 10000 -- the size the benchmark diffs
```
