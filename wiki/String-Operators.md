# String Operators

Operators that work with strings

 These operators provide conversion to string, concatenation and retrieval of character data.

**[Operator + (String Concatenation)](Operator-String-Concatenation)**

Concatenates two strings.

**[Operator & (String Concatenation With Conversion)](Operator-String-Concatenation-with-Conversion)**

Concatenates two values converted to strings.

**[Operator Strptr (String Pointer)](Operator-Strptr-String-Pointer)**

Returns the address of a string's character data.
