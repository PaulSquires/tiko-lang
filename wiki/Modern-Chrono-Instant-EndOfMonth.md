# Instant.EndOfMonth

## Syntax

```freebasic
Instant.EndOfMonth
```

## Examples

```freebasic
#import "std/chrono"
using chrono

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.EndOfMonth( ).ToIsoString( )     '' 2026-08-31T23:59:59.9999999
print d.EndOfMonth( ).Day                '' 31
```
