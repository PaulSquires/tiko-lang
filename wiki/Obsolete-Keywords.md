# Obsolete Keywords

Along the way FB has had a few keywords changed. Here is the list of those no longer supported. Old code must be updated if recompiled.

 OPEN "CON:"

Use [Open Cons](Open-Cons)

OPEN "ERR:"

Use [Open Err](Open-Err)

OPEN "PIPE:"

Use [Open Pipe](Open-Pipe)

POKEI

Use [Poke (Integer,Address,N)](Poke)

POKES

Use [Poke (Short,Address,N)](Poke)

SCREENINFO (Function returning a pointer to a structure)

Use [Screeninfo, Sub Returning Values In Its Arguments](Screeninfo)

VAL64

Use [Vallng()](Vallng)

GOSUB

Do not use [GoSub](Gosub) in SUBs or FUNCTIONs anymore; allowed in `-lang qb` mode.
