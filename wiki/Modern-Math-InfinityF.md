# InfinityF

Returns positive infinity as a Single.

## Syntax

```freebasic
InfinityF( )
```

## Examples

```freebasic
#import "std/numeric"
using numeric

dim as float32 inf = InfinityF( )

print IsInfinite( inf )      '' true

'' The single-precision infinity, for the same reason NaNF exists
```
