# InfinityF

## Syntax

```freebasic
InfinityF( )
```

## Examples

```freebasic
#import "std/numeric"
using FB

dim as float32 inf = InfinityF( )

print IsInfinite( inf )      '' true

'' The single-precision infinity, for the same reason NaNF exists
```
