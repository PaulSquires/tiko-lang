# TuiSizeOf

## Syntax

```freebasic
TuiSizeOf( byval cols as int32, byval rows as int32 ) as TuiSize
```

## Description

Builds a TuiSize.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiSize s = TuiSizeOf( 100, 30 )
print s.cols * s.rows             '' 3000 cells
```
