# TuiCanvas.CellCols

## Syntax

```freebasic
TuiCanvas.CellCols( ) as int32
```

## Description

The canvas width in terminal cells.

## Example

```freebasic
#import "std/tui"
using FB

print TuiCanvas( 40, 10 ).CellCols( )          '' 40
```
