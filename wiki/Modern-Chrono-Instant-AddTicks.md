# Instant.AddTicks

## Syntax

```freebasic
Instant.AddTicks( n )
```

## Examples

```freebasic
#include once "fb/chrono.bi"
using FB

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.AddTicks( DT_TICKS_PER_HOUR ).Hour        '' 15

'' The exact form: 100 ns each, no rounding anywhere
print d.AddTicks( 1 ).Ticks - d.Ticks            '' 1
```
