# TuiInput.Queued

## Syntax

```freebasic
TuiInput.Queued( ) as long
```

## Description

Events parsed and waiting to be taken.

## Example

```freebasic
#include once "fb/tui.bi"
using FB

dim as TuiInput keys
keys.Feed( "abc" )                '' three complete characters
print keys.Queued( ) >= 0          '' -1 (true)
print keys.NextEvent( ).Value( ).key.ch = asc( "a" ) '' -1 (true)
```
