# #print

Preprocessor diagnostic directive

## Syntax

```freebasic
#print text
```

## Description

Causes compiler to output `text` to screen during compilation.

## Remarks

### Differences from QB

- New to FreeBASIC

### See also

- [`#error`](procedures-Error)

## Examples

`#print Now compiling module foo`
