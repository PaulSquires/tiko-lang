# Instant.DaysInYear

Returns 365 or 366, the number of days in a year.

## Syntax

```freebasic
Instant.DaysInYear( y )
```

## Examples

```freebasic
#import "std/chrono"
using chrono

print DateTime.DaysInYear( 2025 )       '' 365
print DateTime.DaysInYear( 2024 )       '' 366
```
