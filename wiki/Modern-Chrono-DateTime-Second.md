# DateTime.Second

Returns the second, 0 to 59.

## Syntax

```freebasic
DateTime.Second
```

## Examples

```freebasic
#import "std/chrono"
using chrono

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.Second               '' 5

'' No leap seconds: a day is always exactly 86400 seconds
```
