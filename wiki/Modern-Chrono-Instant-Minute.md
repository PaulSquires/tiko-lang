# DateTime.Minute

Returns the minute, 0 to 59.

## Syntax

```freebasic
DateTime.Minute
```

## Examples

```freebasic
#import "std/chrono"
using chrono

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.Minute               '' 30
```
