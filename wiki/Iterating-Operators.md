# Iterating Operators

Operators that work with iterator objects

 These operators allow objects of user-defined types to be used as iterators and step values in [`For...Next`](For-Next) statements.

**[Operator For](Operator-for-Iteration)**

Allows an iterator a chance to prepare for the loop.

**[Operator Step](Operator-Step-Iteration)**

Increments an iterator object.

**[Operator Next](Operator-Next-Iteration)**

Determines if the loop should terminate or continue iterating.
