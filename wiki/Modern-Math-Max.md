# Max

Returns the larger of two values; a NaN argument gives NaN.

## Syntax

```freebasic
Max( a, b )
```

## Examples

```freebasic
#import "std/numeric"
using numeric

dim as float64 a = 3.0, b = 7.0
print Max( a, b )            '' 7

dim as int32 i = 3, j = 7
print Max( i, j )            '' 7
```
