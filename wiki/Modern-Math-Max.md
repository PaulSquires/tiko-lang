# Max

## Syntax

```freebasic
Max( a, b )
```

## Examples

```freebasic
#include once "fb/math.bi"
using FB

dim as double a = 3.0, b = 7.0
print Max( a, b )            '' 7

dim as long i = 3, j = 7
print Max( i, j )            '' 7
```
