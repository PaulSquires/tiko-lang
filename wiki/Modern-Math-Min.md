# Min

## Syntax

```freebasic
Min( a, b )
```

## Examples

```freebasic
#import "std/numeric"
using numeric

dim as float64 a = 3.0, b = 7.0
print Min( a, b )            '' 3

dim as int32 i = 3, j = 7
print Min( i, j )            '' 3 -- generic over the numeric types
```
