# TuiTerminal.Pending

## Syntax

```freebasic
TuiTerminal.Pending( ) as int32
```

## Description

Bytes buffered and not yet flushed.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiTerminal term
print term.Pending( )             '' 0
term.Write( "12345" )
print term.Pending( )             '' 5
```
