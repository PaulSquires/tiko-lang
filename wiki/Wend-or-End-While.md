# Wend (Or 'End While')

Control flow statement.

## Syntax

```freebasic
While [condition]
[statement block]
Wend '' or End While
```

## Description

`Wend` specifies the end of a [`While...Wend`](While-Wend-or-While-End-While) loop block.

## Remarks

### Version

- Since fbc 1.20.0: `End While` equivalent to `Wend`

### Differences from QB

- None, except for the `End While` syntax (equivalent to `Wend`) specific to FreeBASIC.
