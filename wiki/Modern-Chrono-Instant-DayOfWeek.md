# Instant.DayOfWeek

## Syntax

```freebasic
Instant.DayOfWeek
```

## Examples

```freebasic
#include once "fb/chrono.bi"
using FB

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
'' ISO NUMBERING: Monday 1 through Sunday 7
print d.DayOfWeek            '' 4 -- a Thursday
print DateTime.WeekdayName( d.DayOfWeek )        '' Thursday
```
