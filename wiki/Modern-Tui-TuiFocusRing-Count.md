# TuiFocusRing.Count

## Syntax

```freebasic
TuiFocusRing.Count( ) as int32
```

## Description

How many widgets are in the ring.

## Example

```freebasic
#import "std/tui"
using FB

dim as TuiFocusRing ring
print ring.Count( )               '' 0
```
