# TuiFocusRing.Count

Counts the widgets in the Tab order.

## Syntax

```freebasic
TuiFocusRing.Count( ) as int32
```

## Description

How many widgets are in the ring.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiFocusRing ring
print ring.Count( )               '' 0
```
