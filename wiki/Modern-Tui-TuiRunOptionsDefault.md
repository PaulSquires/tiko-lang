# TuiRunOptionsDefault

## Syntax

```freebasic
TuiRunOptionsDefault( ) as TuiRunOptions
```

## Description

60 fps, quit on Ctrl+C.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiRunOptions ro = TuiRunOptionsDefault( )
print ro.fps                      '' 60
print ro.quitOnCtrlC              '' true
```
