# Array Functions

Statements and procedures for working with arrays.

 **Defining Arrays**

Statements that create arrays.

**Clearing Array Data**

Procedures that work with array memory.

**Retrieving Array Size**

Procedures that return the array's length/size and bounds for any array's dimension.

**Retrieving Array Descriptor**

Procedures that return a pointers to an array's descriptor.

***Defining Arrays***

**[Option Dynamic](Option-Dynamic)**

Forces arrays to be defined as variable-length arrays.

**['$Dynamic](Dynamic)**

Alternate form of the [Option Dynamic](Option-Dynamic) statement.

**[Option Static](Option-Static)**

Reverts a previous [Option Dynamic](Option-Dynamic) command.

**['$Static](Static)**

Alternate form of the [Option Static](Option-Static) statement.

**[Dim](Dim)**

Defines any type of array.

**[ReDim](Redim)**

Defines and resizes variable-length arrays.

**[Preserve](Preserve)**

Preserves array contents when used with [ReDim](Redim).

***Clearing Array Data***

**[Erase](Erase)**

Destroys variable-length array elements and initializes fixed-length array elements.

***Retrieving Array Size***

**[Arraylen](Arraylen)**

Returns the total number of array elements.

**[Arraysize](Arraysize)**

Returns the total array size (in bytes).

**[LBound](Lbound)**

Returns the lower bound of an array's dimension.

**[UBound](Ubound)**

Returns the upper bound of an array's dimension.

***Retrieving Array Descriptor***

**[Array\[Const\]Descriptorptr](Fbarray-Array-Descriptor-Structure-and-Access)**

Returns a \[constant\] pointer to array's descriptor (FBARRAY).
