# TuiScreen.Rows

## Syntax

```freebasic
TuiScreen.Rows( ) as int32
```

## Description

Current height in cells.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiScreen scr
scr.Resize( 100, 30 )
print scr.Rows( )                 '' 30
```
