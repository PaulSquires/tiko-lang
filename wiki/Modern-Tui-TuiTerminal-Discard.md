# TuiTerminal.Discard

## Syntax

```freebasic
TuiTerminal.Discard( )
```

## Description

Throws the pending buffer away without writing it. For abandoning a frame you decided not to draw.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiTerminal term
term.Write( "half a frame" )
term.Discard( )
print term.Pending( )             '' 0
```
