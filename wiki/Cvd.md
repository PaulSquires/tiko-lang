# CVD

Reads a Double back from an 8-byte string.

## Syntax

```freebasic
Declare Function CVD ( ByVal l As LongInt ) As Double
Declare Function CVD ( ByRef str As Const String ) As Double
```

## Parameters

- `l`
- `str`

## Description

Does a binary copy from a 64-bit [`LongInt`](Longint) or 8-byte [`String`](String) to a [`Double`](Double) variable. A value of zero (`0.0`) is returned if the string is less than 8 bytes in length. The result will make sense only if the parameter contained a IEEE-754 formatted double-precision value, such as one generated by [`CVLongInt`](Cvlongint) or [`MKD`](Mkd).

 This function is useful to read numeric values from buffers without using a [`Type`](Type-Udt) definition.

## Return Value

Returns a [`Double`](Double) value holding a binary copy of the input value.

## Remarks

### Usage

```freebasic
result = CVD( l )

result = CVD( str )
```

### Differences from QB

- QB did not support integer arguments.

### See also

- [`MKD`](Mkd)
- [`CVS`](Cvs)
- [`CVLongInt`](Cvlongint)

## Examples

```freebasic
Dim d As Double, l As LongInt

d = 1.125

l = CVLongInt(d)

Print Using "l = _&H&"; Hex(l)

Print Using "cvd(i) = &"; CVD(l)
```
