# Operators

Procedures that operate on one or more operands.

 FreeBASIC has numerous *operators* that perform a certain function with their *operands*. Many operators use a "`operand operator operand`" syntax, like [`Operator = (Assignment)`](Operator-Assign) or [`Operator +`](Operator-Addition), while others are called like normal procedures, like [`Operator Strptr`](Operator-Strptr-String-Pointer).

**[Assignment operators](Assignment-Operators)**

Operators which assign the value of one operand to the other.

**[Arithmetic operators](Arithmetic-Operators)**

Operators that perform mathematical computations on their operands and return the result.

**[Conditional operators](Relational-Operators)**

Operators that compare the relationship between their operands.

**[Logical operators](Logical-Operators)**

Operators that perform bitwise computations with their operands and return the result.

**[Short circuit operators](Short-Circuit-Operators)**

Operators that perform short circuit evaluations with their operands and return the result.

**[Indexing operators](Indexing-Operators)**

Operators that return references to variables or objects based on an index value.

**[String operators](String-Operators)**

Operators overloaded to work with strings.

**[Preprocessor operators](Preprocessor-Operators)**

Operators that control preprocessor behavior.

**[Pointer operators](Pointer-Operators)**

Operators that work with pointers and addresses.

**[Type or Class operators](Type-or-Class-Operators)**

Operators that provide access to [Type](Type-Udt) or [Class](Class) members.

**[Memory operators](Memory-Operators)**

Operators that allocate memory for and construct objects.

**[Iterating operators](Iterating-Operators)**

Operators that use iterator objects in [`For...Next`](For-Next) statements.
