# Instant.Month

## Syntax

```freebasic
Instant.Month
```

## Examples

```freebasic
#include once "fb/chrono.bi"
using FB

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.Month                '' 8 -- ONE-BASED, January is 1
print DateTime.MonthName( d.Month )      '' August
```
