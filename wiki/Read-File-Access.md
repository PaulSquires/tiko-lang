# Read (File Access)

Opens a Binary or Random file for reading only, in an Access clause.

## Syntax

```freebasic
Open filename As String For Binary Access Read As #filenum As Integer
```

## Description

Specifier for the [`Access`](Access) clause in the [`Open`](Open) statement. `Read` specifies that the file is accessible for input.
