# Instant.Second

## Syntax

```freebasic
Instant.Second
```

## Examples

```freebasic
#import "std/chrono"
using FB

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.Second               '' 5

'' No leap seconds: a day is always exactly 86400 seconds
```
