# Instant.AddMinutes

## Syntax

```freebasic
Instant.AddMinutes
```

## Examples

```freebasic
#import "std/chrono"
using chrono

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.AddMinutes( 30 ).Hour        '' 15
print d.AddMinutes( 1.5 ).Second     '' 35 -- fractional minutes are fine
```
