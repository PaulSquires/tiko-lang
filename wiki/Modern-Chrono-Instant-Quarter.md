# Instant.Quarter

## Syntax

```freebasic
Instant.Quarter
```

## Examples

```freebasic
#import "std/chrono"
using chrono

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.Quarter              '' 3 -- calendar quarters, 1 to 4
```
