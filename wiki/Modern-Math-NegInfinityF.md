# NegInfinityF

## Syntax

```freebasic
NegInfinityF( )
```

## Examples

```freebasic
#include once "fb/math.bi"
using FB

dim as single ninf = NegInfinityF( )

print IsInfinite( ninf )     '' true
print IsNegative( ninf )     '' true
```
