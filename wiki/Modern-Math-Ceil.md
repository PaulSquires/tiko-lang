# Ceil

## Syntax

```freebasic
Ceil( x )
```

## Examples

```freebasic
#import "std/numeric"
using FB

print Ceil( 2.1 )            '' 3
print Ceil( -2.7 )           '' -2 -- towards POSITIVE infinity

print Floor( -2.7 )          '' -3, the other direction
```
