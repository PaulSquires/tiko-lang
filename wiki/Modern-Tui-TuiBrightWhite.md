# TuiBrightWhite

## Syntax

```freebasic
TuiBrightWhite( ) as TuiColor
```

## Description

Shorthand for TuiAnsi( TUIC_BRIGHTWHITE ) -- palette index 15.

## Example

```freebasic
#import "std/tui"
using FB

dim as TuiColor c = TuiBrightWhite( )
print c.Index( )                  '' 15
dim as TuiStyle s = TuiStyleOf( c, TuiDefaultColor( ), TUIATTR_BOLD )
print s.HasAttr( TUIATTR_BOLD )   '' true
```
