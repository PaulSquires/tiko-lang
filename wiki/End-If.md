# End If

Control flow statement for conditional branching.

## Syntax

```freebasic
If expression Then [statement(s)] [Else [statement(s)]] [End If]
If expression Then : [statement(s)] [Else [statement(s)]] : End If
If expression Then
[statement(s)]
[ ElseIf expression Then ]
[statement(s)]
[ Else ]
[statement(s)]
```

## Remarks

### Differences from QB

- END IF was not supported in single-line IFs in QBASIC.
