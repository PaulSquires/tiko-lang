# CVS

Reads a Single back from a 4-byte string.

## Syntax

```freebasic
Declare Function CVS ( ByVal i As Integer ) As Single
Declare Function CVS ( ByRef str As Const String ) As Single
```

## Parameters

- `i`
- `str`

## Description

Does a binary copy from a 32-bit [`Integer`](Integer) or 4-byte [`String`](String) to a [`Single`](Single) variable. A value of zero (`0.0`) is returned if the string is less than 4 bytes in length. The result will make sense only if the parameter contained a IEEE-754 formatted single-precision value, such as one generated by [`CVI`](Cvi) or [`MKS`](Mks).

 This function is useful to read numeric values from buffers without using a [`Type`](Type-Udt) definition.

## Return Value

Returns a [`Single`](Single) value holding a binary copy of the input value.

## Remarks

### Usage

```freebasic
result = CVS( i )

result = CVS( str )
```

### Differences from QB

- QB did not support integer arguments.

### See also

- [`MKS`](Mks)
- [`CVD`](Cvd)
- [`CVI`](Cvi)

## Examples

```freebasic
Dim f As Single, i As Integer

f = 1.125

i = CVI(f)

Print Using "i = _&H&"; Hex(i)

Print Using "cvs(i) = &"; CVS(i)
```
