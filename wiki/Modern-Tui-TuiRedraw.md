# TuiRedraw

## Syntax

```freebasic
TuiRedraw( ) as TuiCmd
```

## Description

Mark the screen dirty so the next frame is rendered. The diff still applies -- a redraw after a change that turns out to be invisible costs zero bytes.

## Example

```freebasic
#import "std/tui"
using tui

print TuiRedraw( ).kind = TUICMD_REDRAW '' -1 (true)
```
