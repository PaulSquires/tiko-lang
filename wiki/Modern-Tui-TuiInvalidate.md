# TuiInvalidate

## Syntax

```freebasic
TuiInvalidate( ) as TuiCmd
```

## Description

Force a FULL repaint rather than a diff. Use it after anything that changed the screen behind the module's back.

## Example

```freebasic
#import "std/tui"
using FB

print TuiInvalidate( ).kind = TUICMD_INVALIDATE '' -1 (true)
```
