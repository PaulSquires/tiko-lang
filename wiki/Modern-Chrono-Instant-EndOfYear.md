# Instant.EndOfYear

## Syntax

```freebasic
Instant.EndOfYear
```

## Examples

```freebasic
#import "std/chrono"
using FB

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.EndOfYear( ).ToIsoString( )      '' 2026-12-31T23:59:59.9999999
```
