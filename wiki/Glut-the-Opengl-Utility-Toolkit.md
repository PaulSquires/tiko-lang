# GLUT, the OpenGL Utility Toolkit

GLUT is a helper library that can be used to create OpenGL applications. It allows easy creation of a window with an OpenGL drawing context and also handles events such as mouse and keyboard input or timers. GLUT appears to be no longer maintained, however there is an active alternative: [freeglut](Free-Alternative-to-the-Opengl-Utility-Toolkit).

 Website: http://www.opengl.org/resources/libraries/glut/  
 Platforms supported: Win32  
 Headers to include: GL/glut.bi  
 Header version: 3.7  
 Examples: in examples/graphics/OpenGL/
