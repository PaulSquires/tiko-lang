# Instant.Subtract

## Syntax

```freebasic
Instant.Subtract( span )
```

## Examples

```freebasic
#import "std/chrono"
using chrono

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.Subtract( TimeSpan.FromHours( 2 ) ).Hour  '' 12

'' Overflow past MinValue yields Invalid rather than wrapping
print DateTime.MinValue( ).Subtract( TimeSpan.FromTicks( 1 ) ).IsValid    '' false
```
