# TuiFrame.CursorVisible

## Syntax

```freebasic
TuiFrame.CursorVisible( ) as boolean
```

## Description

Whether this frame asked for a cursor.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiScreen scr
scr.Resize( 10, 3 )
dim as TuiFrame ptr f = scr.BeginFrame( )
print f->CursorVisible( )         '' false -- nothing has asked
```
