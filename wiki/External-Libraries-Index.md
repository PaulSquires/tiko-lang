# External Libraries Index

This is the list of external library bindings currently included in FreeBASIC. Visit the link shown for each individual library below to see more information. To obtain a needed external library or DLL, please visit the library's homepage. If you translated additional headers, or updated existing ones, please post them on the [FreeBASIC forum](http://www.freebasic.net/forum/) or submit them to the [compiler project's patch tracker](http://sourceforge.net/projects/fbc/)!

 ***Graphical/test-based user interfaces***

[CGUI](Cgui) - Library for making GUIs in a simple way.  
 [Curses](Curses) - Standardized console user interface library.  
 [GTK+](Gtk-the-Gimp-Toolkit) - Cross-platform Graphical User Interface Library.  
 [IUP](Iup) - Portable toolkit for building graphical user interfaces.  
 [wxC](Wx-C-C-Interface-for-Wxwidgets) - Cross-platform Graphical User Interface Library.  
 [Windows API](Windows-Api) - Windows GUIs and more  
 [X11](X11) - Windowing system commonly used on Linux systems

***Graphics***

[Allegro](Allegro) - Game programming library.  
 [DUGL](Dugl) - Game and graphics library for DOS.  
 [caca](Caca) - A colour ASCII art library.  
 [Cairo](Cairo) - 2D graphics library with support for multiple output devices.  
 [DISLIN](Dislin) - Library of subroutines and functions that display data graphically.  
 [freeglut](Free-Alternative-to-the-Opengl-Utility-Toolkit) - A free alternative to [GLUT](Glut-the-Opengl-Utility-Toolkit), an OpenGL library for window creation and callback-based input handling  
 [FreeImage](Freeimage) - Open Source library to support popular graphics image formats.  
 [Freetype2](Freetype2) - A Free, High-Quality, and Portable Font Engine.  
 [GD](Gd) - Open source code library for the dynamic creation of images by programmers.  
 [GIFLIB](Giflib) - Portable tools and library routines for working with GIF images.  
 [GLUT](Glut-the-Opengl-Utility-Toolkit) - the original (but now inactive) OpenGL Utility Toolkit  
 [GLFW](Glfw-an-Opengl-Library) - An OpenGL library for creating an OpenGL window and handling input from the user's main loop  
 [GRX](Grx) - 2D graphics library.  
 [IL (DevIL)](Devil) - A full featured cross-platform image library.  
 [japi](Java-Application-Programming-Interface) - Open source free software GUI toolkit using Java's AWT Toolkit.  
 [jpeglib](Jpeglib) - Cross-platform library for reading/writing jpeg images.  
 [JPGalleg](Jpgalleg) - A small add-on for Allegro that adds JPG images handling capabilities to the library.  
 [libpng](Libpng) - Allows reading and writing PNG images.  
 [OpenGL](Opengl-the-Open-Graphics-Language) - Cross-platform 3D Graphics library.  
 [PDFlib](Pdflib) - Portable library for dynamically generating PDF documents.  
 [SDL](Sdl-the-Simple-Directmedia-Layer) - Cross-platform multimedia library.  
 [TinyPTC](Tinyptc) - A small and easy to use framebuffer graphics library.

***Music/Sound, Audio/Video***

[BASS](Bass) - Audio library for use in Windows with a beta for Linux.  
 [BASSMOD](Bassmod) - BASSMOD is a MOD only (XM, IT, S3M, MOD, MTM, UMX) version of BASS  
 [Flite](Flite) - Run time speech synthesis engine  
 [FMOD](external-libraries-index-Fmod) - Audio library supporting just about any format.  
 [MediaInfo](Mediainfo) - Library to read out technical and tag information from many media file formats  
 [mpg123](Mpg123) - MPEG (including MP3) decoder library  
 [Ogg](Libogg) - Ogg multimedia container format creation/decoder library  
 [OpenAL](Openal) - Cross-platform 3D audio API.  
 [PortAudio](Portaudio) - Cross-platform audio I/O library  
 [sfx](Sfx) - Freebasic sfx library is cross-platform and comes for Windows, Linux, Dos  
 [sndfile](Libsndfile) - Library to read/write/convert audio files in various formats  
 [VLC](Libvlc) - Audio/video playback  
 [Vorbis](Libvorbis) - Ogg Vorbis audio compression library

***Database***

[GDBM](Gdbm-the-Gnu-Database-Manager) - Database functions using extensible hashing, primarily for storing key/data pairs to data files  
 [MySQL](Mysql) - High-Quality, widely used database engine.  
 [PostgreSQL](Postgresql) - Free software object-relational database management system  
 [SQLite](Sqlite) - Small C library that implements a self-contained, embeddable, zero-configuration SQL database engine.

***Development Helpers***

[CUnit](Cunit) - Lightweight system for writing, administering, and running unit tests in C.  
 [GDSL](Gdsl-the-Generic-Data-Structures-Library) - The Generic Data Structures Library is a collection of routines for generic data structures.  
 [gettext (includes libintl)](Gettext) - Internationalization mechanism  
 [GNU ASpell](Gnu-Aspell) - Free and Open Source spell checker.  
 [libbfd](Bfd-the-Binary-File-Descriptor-Library) - Allows applications to use the same routines to operate on object files whatever the object file format.

***Embeddable Languages***

[JNI](Jni-the-Java-Native-Interface) - Standard programming interface for writing Java native methods and embedding the Java virtual machine into native applications.  
 [json-c](Json-C) - A JSON implementation in C  
 [libffi](Libffi) - Foreign function interface and closure library  
 [libjit](Libjit) - Runtime (just in time) compilation library  
 [Lua](Lua) - Lightweight, embeddable scripting engine using the Lua language.  
 [SpiderMonkey](Spidermonkey) - Embeddable javascript engine.

***Cryptography***

[cryptlib](Cryptlib) - A powerful security toolkit which allows even inexperienced crypto programmers to easily add encryption and authentication services to their software.  
 [UUID](Uuid-Library) - Universally Unique Identifier generation and parsing library

***Mathematics***

[big_int](Big-Int) - Library for using arbitrarily large integers.  
 [Chipmunk](Chipmunk-Physics) - 2D rigid body physics library  
 [GMP](Gmp-the-Gnu-Multiple-Precision-Arithmetic-Library) - Free library for arbitrary precision arithmetic, operating on signed integers, rational numbers, and floating point numbers.  
 [GSL](Gsl-the-Gnu-Scientific-Library) - Provides a wide range of mathematical routines such as random number generators, special functions and least-squares fitting.  
 [Newton](Newton) - Integrated solution for real time simulation of physics environments.  
 [ODE](Ode-the-Open-Dynamics-Engine) - Open source, high performance library for simulating rigid body dynamics.

***Networking***

[cgi-util](Cgi-Util) - Small C library for creating CGI programs for Websites.  
 [curl](Curl) - Free and easy-to-use client-side URL transfer library supporting almost every protocol.  
 [FastCGI](Fastcgi) - Open extension to CGI that provides high performance without the limitations of server specific APIs.  
 [ZeroMQ](Zeromq) - High-performance asynchronous messaging library

***eXtensible Markup Language (XML)***

[Expat](Expat) - Stream oriented XML parser library with several useful features.  
 [libxml](Libxml2) - De-facto standard library for accessing xml files.  
 [libxslt](Libxslt) - XSLT itself is a an XML language to define transformation for XML.  
 [Mini-XML](Mxml-Mini-Xml) - Small XML parsing library that you can use to read XML and XML-like data files in your application.

***Regular Expressions***

[PCRE](Pcre-Perl-Compatible-Regular-Expressions) - Regular expression pattern matching using the same syntax as Perl.  
 [TRE](Tre-Regex-Matching-Library) - Lightweight, robust, and efficient POSIX compliant regexp matching library.

***Compression***

[bzip2](Libbzip2) - For reading/writing .bz2 files or in-memory (de)compression using the bzip2 algorithms  
 [libzip](Libzip) - Easy-to-use library for creating and unpacking .zip files  
 [liblzma](Liblzma) - Strong LZMA-based compression library used for .lzma and .xz file formats  
 [LZO](Lzo) - Offers fast compression and very fast decompression.  
 [QuickLZ](Quicklz) - Very fast Compression Library  
 [zlib](Zlib) - Lossless data compression library unencumbered by patents.

***System APIs***

[C Runtime Library](Crt-the-C-Runtime-Library)  
 [DOS API](Dos-Api)  
 [disphelper](Disphelper) - Helper library to use COM objects from plain C  
 [GLib](Glib) - GNOME's universal cross-platform software utility library  
 [Windows API](Windows-Api)  
 [X11](X11) - Windowing system commonly used on Linux systems
