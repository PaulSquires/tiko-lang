# Compiler Switches

Statements that affect how code is compiled.

Description

These statements affect how the compiler declares variables, arrays and procedures, parses string literals, passes procedure parameters and more.

***Metacommands***

- ['$Dynamic](Dynamic)
- ['$Include](Include)
- ['$Static](Static)
- ['$Lang](Lang)

- [Option Nogosub](Option-Nogosub)
- [Option NoKeyword](Option-Nokeyword)
- [Option Private](Option-Private)

Dialect Differences

- [`DefLongInt`](Deflongint) and [`Defulongint`](Defulongint) available only in the *[-lang fblite](Compiler-Option-Lang)* dialect.
  `OPTION` statements are available only in the *[-lang fblite](Compiler-Option-Lang)* and *[-lang qb](Compiler-Option-Lang)* dialects only.
