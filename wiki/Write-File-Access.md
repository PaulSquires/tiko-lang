# Write (File Access)

File access specifier

## Syntax

```freebasic
Open filename As String For Binary Access Write As #filenum As Integer
```

## Description

Specifier for the [`Access`](Access) clause in the [`Open`](Open) statement. `Write` specifies that the file is accessible for output.
