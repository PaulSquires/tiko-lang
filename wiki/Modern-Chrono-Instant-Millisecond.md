# Instant.Millisecond

## Syntax

```freebasic
Instant.Millisecond
```

## Examples

```freebasic
#import "std/chrono"
using chrono

dim as DateTime d = DateTime( 2026, 8, 13, 14, 30, 5, 123 )
print d.Millisecond          '' 123 -- within the second, 0 to 999
```
