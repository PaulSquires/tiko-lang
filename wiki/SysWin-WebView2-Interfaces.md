# WebView2 interfaces and types

Lists the WebView2 interfaces, enumerations and structures that sys/win/webview2 declares.

[CWebView2](CWebView2) wraps the everyday calls. Everything else WebView2 offers is reached
through the interfaces listed here: [GetWebViewPtr](CWebView2#getwebviewptr),
[GetControllerPtr](CWebView2#getcontrollerptr) and [GetEnvironmentPtr](CWebView2#getenvironmentptr)
return the three a program starts from.

**Calling a method.** Each interface is a type whose methods are called directly with `->`, as
in `pCore->Navigate( "https://example.com/" )`. Every method returns an `HRESULT`, `S_OK` on
success; values come back through a pointer argument. A property is a `get_` method that reads it
and, when it can be changed, a `put_` method that sets it. Yes-or-no values are `LONG`s
(`WINBOOL`): `TRUE` or `FALSE`.

**Example**

```freebasic
dim pCore as ICoreWebView2 ptr = CWebView2Ptr( hwnd )->GetWebViewPtr()
dim pwszUri as LPWSTR
if pCore->get_Source( @pwszUri ) = S_OK then
    dim uri as ustring = *pwszUri
    CoTaskMemFree( pwszUri )
    print uri
end if
```

**What must be released.** A string a method returns (an `LPWSTR` written through an
`LPWSTR ptr`) is the caller's: free it with `CoTaskMemFree`. An interface a method returns
carries a reference: call its `Release` when done. The pointers from `GetWebViewPtr` and the
other two `CWebView2` getters, and the `sender` and `args` a handler receives, are borrowed: do
not release them, and call `AddRef` on one to keep it.

**Later versions.** `ICoreWebView2_2` to `ICoreWebView2_28`, `ICoreWebView2Controller2` and the
other names ending in a number each extend the one before and add only the members listed. Ask
the object for the version you need with `QueryInterface` and its `IID_` variable; on a WebView2
runtime too old to have it, the call fails with `E_NOINTERFACE`.

**Example**

```freebasic
dim p8 as ICoreWebView2_8 ptr
if CWebView2Ptr( hwnd )->GetWebViewPtr()->QueryInterface( @IID_ICoreWebView2_8, cast( any ptr ptr, @p8 ) ) = S_OK then
    p8->put_IsMuted( TRUE )
    p8->Release()
end if
```

**Names.** Each interface name is an alias of a type with the same name and a trailing
underscore, `ICoreWebView2` of `ICoreWebView2_`, which extends `ComUnknown` (the `IUnknown`
methods `QueryInterface`, `AddRef`, `Release`) or the interface it is a later version of.
Programs use the name without the underscore. Every interface also has its identifier as a shared
`GUID` named `IID_` and the interface name: `IID_ICoreWebView2_8`.

**Callbacks.** The handler interfaces, and the options interfaces marked as supplied by the
program, are implemented by the program, not by WebView2. For the common events, extend one of
the classes on [WebView2 event handlers](SysWin-WebView2-Events).

## Example

A web view whose context menu and status bar are turned off through its settings interface, and
whose sound is muted through `ICoreWebView2_8`. Like every WebView2 program it needs
`WebView2Loader.dll` beside the executable; the WebView2 examples in the toolchain's
`examples/win64/` folder come with one.

```freebasic
#import "sys/win"
#import "sys/win/gui"
#import "sys/win/webview2"
using win, gui, webview2

declare function WndProc( byval hwnd as HWND, byval uMsg as UINT, byval wParam as WPARAM, byval lParam as LPARAM ) as LRESULT

function main() as long
    SetProcessDpiAwareness( PROCESS_SYSTEM_DPI_AWARE )
    dim pWindow as CWindow = "WebView2Settings"
    dim hWin as HWND = pWindow.Create( NULL, "WebView2 interfaces", @WndProc )
    pWindow.SetClientSize( 800, 500 )
    pWindow.Center()
    dim ustrFolder as ustring = GetTempPath() & "tkWebView2"
    dim pWebView2 as CWebView2 = CWebView2( hWin, ustrFolder )
    if pWebView2.IsReady( 10000 ) then
        dim pCore as ICoreWebView2 ptr = pWebView2.GetWebViewPtr()
        dim pSettings as ICoreWebView2Settings ptr
        if pCore->get_Settings( @pSettings ) = S_OK then
            pSettings->put_AreDefaultContextMenusEnabled( FALSE )
            pSettings->put_IsStatusBarEnabled( FALSE )
            pSettings->Release()
        end if
        dim p8 as ICoreWebView2_8 ptr
        if pCore->QueryInterface( @IID_ICoreWebView2_8, cast( any ptr ptr, @p8 ) ) = S_OK then
            p8->put_IsMuted( TRUE )
            p8->Release()
        end if
        pWebView2.NavigateToString( "<h1>No context menu here</h1><p>Right-click does nothing.</p>" )
    end if
    return pWindow.DoEvents( SW_NORMAL )
end function

function WndProc( byval hwnd as HWND, byval uMsg as UINT, byval wParam as WPARAM, byval lParam as LPARAM ) as LRESULT
    select case uMsg
        case WM_SIZE
            dim pWebView2 as CWebView2 ptr = CWebView2Ptr( hwnd )
            if pWebView2 then
                dim rc as RECT
                GetClientRect( hwnd, @rc )
                pWebView2->SetBounds( rc )
            end if
            return 0
        case WM_DESTROY
            PostQuitMessage( 0 )
            return 0
    end select
    return DefWindowProcW( hwnd, uMsg, wParam, lParam )
end function

end main()
```
