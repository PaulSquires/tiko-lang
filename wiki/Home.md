# tiko-lang Wiki

**A FreeBASIC compiler with a portable Unicode string type, generics, an iterator protocol, `FOR EACH`, tuples and multiple return, a standard container library, a modern date/time library, a modern filesystem library, `defer`, and lambdas — built on fbc 1.20.0, with the existing language left untouched.**

This wiki is two things in one place:

1. **The FreeBASIC language reference** — the complete FreeBASIC 1.20.0 manual, every keyword, statement, operator, function, tutorial and compiler page.
2. **The tiko-lang additions** — everything this compiler adds on top. Those pages carry the badge below and a ✨ in every index, so you always know which is which.

[![tiko-lang](https://img.shields.io/badge/tiko--lang-extension-8A2BE2?style=flat-square)](What-Is-tiko-lang)

> ✨ **tiko-lang extension.** A page marked like this documents a feature added by tiko-lang. It is **not** available in stock FreeBASIC 1.20.0.
