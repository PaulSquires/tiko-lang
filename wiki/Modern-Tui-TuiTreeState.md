# TuiTreeState

## Syntax

```freebasic
type TuiTreeState
    as int32 selected, offset
end type
```

## Description

A tree's selection and scroll, owned by you. Expansion state lives in the tree itself.

## Example

```freebasic
#import "std/tui"
using tui

dim as TuiTreeState st
print st.selected, st.offset      '' 0 0
```
