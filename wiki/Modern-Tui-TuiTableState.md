# TuiTableState

## Syntax

```freebasic
type TuiTableState
    as int32 selected, offset
end type
```

## Description

A table's selection and scroll, owned by you.

## Example

```freebasic
#import "std/tui"
using FB

dim as TuiTableState st
st.selected = 4
print st.selected, st.offset      '' 4 0
```
