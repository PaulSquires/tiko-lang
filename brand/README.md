| File | Use |
| --- | --- |
| `tiko-logo-on-light.svg` | Main logo (mark + wordmark) on light backgrounds |
| `tiko-logo-on-dark.svg` | Main logo on dark backgrounds |
| `tiko-mark.svg` | The mark alone: avatars, favicons, app icons |
| `tiko-mascot.svg` | Tiko the bird, the mascot. Illustration only, not a logo |
| `tiko.ico` | Windows icon, 16/24/32/48/64/256 |
| `png/` | Raster exports: mark 16–512, both logos at 752×264, mascot 512 |

## Colours

| Name | Hex | Where |
| --- | --- | --- |
| Violet | `#7B5CFF` → `#4A2FD1` | Mark tile gradient |
| Ink | `#2A1A6E` | Wordmark on light |
| Mint | `#3DF5B0` | The mark's dot and the wordmark dot on light |
| Orange | `#FF8A3D` | Mascot beak, feet and tuft |

The wordmark is drawn as strokes, not set in a font, so it needs no font installed.
Leave clear space of at least half the mark's height around the logo.
