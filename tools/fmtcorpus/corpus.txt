# tools/fmtcorpus/corpus.txt -- THE SHARED FORMAT-STRING CORPUS (docs/tiko-strings/RFC-0002-format.md
# sections 7.1 and 9). One case a line:
#
#     <format literal> | <arguments> | <FE code> <offset> [run]
#
# Split at the LAST two "|". The literal is tiko source -- "...", $"..." or !"..." -- and the arguments are expressions over
# the prelude in gen.py. The expectation is strings.TryFormat's: OK, or the FormatErrorCode name
# without its FE_ and the 0-based offset in UTF-16 units. 'run' marks a refusal the compiler
# cannot see -- a value's, a Formattable's, an argument whose kind is not known, an escaped
# literal -- and must stay silent on. gen.py writes the run-time test and the compile-time test
# from this file; edit here, then run it.
#
