# inc-exclude.txt -- top-level entries of inc/ that a packaged toolchain does NOT ship.
#
# build/package.sh assembles inc/ from the seed's third-party bindings and this tree's own
# inc/, then deletes every entry named here (a file or a whole directory, matched exactly,
# case and all) and refuses to package if a header it still ships includes one of them.
#
# The author's list, 2026-10-10: third-party library bindings tiko does not carry. Kept
# although on the list, because shipped headers include them: string.bi and utf_conv.bi
# (vbcompat.bi; AfxNova's DWSTRING.bi and CPowerTime.inc), sqlite3api.bi (fbsqlite.bi),
# GL (AfxNova's OpenGL classes, examples and templates). Added: libexslt, which includes
# libxml and libxslt and would not compile without them.
#
# A PATH may name a directory below the top (crt/dos). A second word 'unreachable' marks an
# entry that shipped headers DO include, but only under a platform tiko never defines --
# crt/stdio.bi's '#elseif defined(__FB_DOS__)' and the like. Measured 2026-10-10: tiko
# defines __FB_WIN32__ (win64, win64-msvc) or __FB_LINUX__ + __FB_UNIX__ (linux-x86_64),
# never __FB_DOS__, __FB_ANDROID__ or __FB_FREEBSD__, and every such include sits in one of
# those branches (or stdio.bi's other-Unix fallback, after __FB_LINUX__). The guard skips
# these; everything else it still checks.
